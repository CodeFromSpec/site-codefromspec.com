# SPEC/design/theory-index

Layout for the theory index page. Starts as a copy of
the journal theme to serve as an independent starting
point for future visual evolution.

# Private

## Decisions

## Separate theme for theory index

The theory section has its own index theme (distinct
from entry pages) so layout can evolve independently.
Started as a copy of the journal theme.

Considered: reusing the default theme (as journal index
does). Discarded: the human wants both theory themes to
start from the same base (journal) and diverge
independently from each other and from journal.
